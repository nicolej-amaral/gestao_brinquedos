# Gestao_brinquedos

## Proposta do Sistema:

   O sistema apresenta uma estrutura CRUD (Create, Read, Update e Delete), que consiste em criar, ler, atualizar e deletar brinquedos de uma loja. O código está todo em PHP e, para funcionar, é preciso ligar o XAMPP e conectar o banco de dados no site "localhost/phpmyadmin". No sistema é possível cadastrar, editar, excluir e listar brinquedos, facilitando a organização e o gerenciamento dos produtos da loja. Cada função do CRUD possui uma finalidade, permitindo que os dados dos brinquedos sejam adicionados, visualizados, alterados ou removidos quando necessário.
